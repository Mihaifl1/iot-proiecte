# Proiecte IoT (TikTok)

Site static: introduci **numărul din video** → schemă + sketch ESP.

## Link public
După activarea GitHub Pages:
`https://USERNAME.github.io/iot-proiecte/`

## Cum modifici pe GitHub (fără PC)
1. Deschide `index.html` (sau `projects-data.js` pentru proiecte)
2. Buton creion **Edit**
3. Commit changes → site-ul se actualizează

## Cum actualizezi de pe PC
1. Rulezi Manager → **Generează site**
2. Upload fișierele din acest folder pe repo (sau `git push`)

## Activare Pages
Settings → Pages → Deploy from a branch → `main` / root → Save
